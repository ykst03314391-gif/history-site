# 大名になった家臣たち ― 天下人に取り立てられた六人 ― 論文版オリジナル

- 対応するWeb記事（②）：`data/articles/retainers-became-daimyo.md`
- 状態：論証中（「秀長は「補佐役」で満足していたのか」〈`hidenaga-independence`〉の②の比較材料として起こした。六人の事実の多くは一般の知識による仮置きで、典拠は要確認）

## 問い・主張（結論の先出し）

- この記事で問うこと：大名の家臣（一門を含む）が、主家の外に足場を持ち、大名（または大名並み）になれたのはどういうときか。
- 自分の結論（主張）：
  - 六人の行き着いた先は三つに分かれる。①主家を離れて大名になった（立花宗茂・小早川隆景）、②主家の中で主家並みに扱われた（島津義弘・吉川広家・直江兼続）、③主家の国を継いだ（鍋島直茂）。
  - だが入口は同じで、主家の上に立つ天下人（秀吉）が主家を通さずに直接取り立てた（名字・姓・官位・領国・与力）。
  - 秀吉の側の理由は、功への報いに加え、服属させた大名家を内から押さえることにあったとみる（見立て）。島津家で当主の弟・義弘を重んじたのが最もはっきりした例。
  - 家臣が自力で主家の外に出る道はほとんどなく、天下人に引き上げられて初めて立てた。天下人が替われば立場も揺らいだ（吉川広家）。

## 前提・通説の整理

- 一般に言われていること（通説）：六人は「主家を支えた名臣」「秀吉に認められた人物」として個別に語られる。
- 本稿の見方：六人を、天下人・主家・家臣の三者の関係で並べて比べる。

## 論証（出典付き）

### 1. 主家を離れて大名になった

#### 1-1. 立花宗茂（大友家）

- 高橋紹運の子、立花道雪の婿養子。大友家の家臣として立花山城を守る。〔要確認：一般の知識による〕
- 九州平定後の国分け：川角太閤記{{同国柳川の城は立花左近に被遣候城付十三万石扨筑後一国は小早川隆景組下と被仰付}}。〔`reference/wikisource/kawasumi-taikoki.txt`。二次史料〕
  - → 主家の大友家を通さず、秀吉が直接柳川を与えた。筑後は隆景の組下。
- 朝鮮出兵の陣立てに{{同柳川侍従}}（羽柴の名字・侍従）。〔`reference/wikisource/hoan-taikoki.txt`〕
- 関ヶ原で改易、元和6年（1620）に柳川へ復帰。〔要確認〕

#### 1-2. 小早川隆景（毛利家）

- 毛利元就の三男、小早川家を継ぐ。輝元の叔父として本家を支える。〔要確認〕
- 天正13年（1585）、四国攻めの後に伊予を与えられる。〔要確認：宛行の形（隆景宛か毛利宛か）〕
- 天正15年（1587）、九州平定後に筑前ほか。川角太閤記{{小早川隆景へ筑前一国被遣候}}、同じ条に{{隆景舎弟藤四郎秀包には筑後の内久留米にて八万石被遣候}}、筑後を{{小早川隆景組下}}。〔`reference/wikisource/kawasumi-taikoki.txt`〕
- 晩年、いわゆる五大老の一人に数えられる。秀秋（秀吉の正室の甥）を養子に迎える。〔要確認〕

### 2. 主家の中で主家並みに扱われた

#### 2-1. 島津義弘（島津家、当主義久の弟）

- 天正15年の降伏後、豊臣政権は義久とは別に義弘を重んじ、羽柴の名字・官位を与え、島津家を代表する人として扱ったとされる。〔要確認：山本博文『島津義弘の賭け』ほか。知行宛行状の宛所（義弘宛か）〕
- 文禄2年（1593）5月朔日付の秀吉の覚書（高麗陣衆宛）：{{島津又太郎事、島津兵庫頭被㆑属㆓与力㆒上は、軍役已下兵庫頭次第たるへき事なるに、内心は一向不㆓許容㆒之由候}}。九州出馬の折に{{兵庫頭達て歎き申に付て、本知分令㆓安堵㆒畢}}とも。〔`reference/wikisource/hoan-taikoki.txt`。甫庵太閤記に収める文書。原文書は未確認〕
  - → 当主の兄ではなく、弟の義弘に、天下人が一族の与力を付けている。天下人と弟の直接の関係を示す。
- 義弘は兄に背いていないが、家中に二つの柱が立った（いわゆる「両殿」）。〔要確認：研究での位置づけ〕

#### 2-2. 吉川広家（毛利家）

- 吉川元春の三男、兄元長の死後に家督。〔要確認〕
- 天正19年（1591）、出雲・隠岐など14万石ほどで月山富田城へ。秀吉の命とされる。〔要確認：朱印状の宛所（広家宛か輝元宛の内訳か）〕
- 関ヶ原後、岩国へ。毛利家は家臣として扱い、諸侯に列したのは慶応4年（1868）。〔要確認〕
  - → 天下人の取り立てで大名並みになっても、次の天下人が認めなければ家臣に戻る。

#### 2-3. 直江兼続（上杉家）

- 天正16年（1588）、景勝の上洛の折に豊臣姓を許され、従五位下山城守に叙任とされる。〔要確認：『上杉家文書』・『上杉家御年譜』に当たる〕
- 慶長3年（1598）、景勝の会津移封に伴い米沢30万石（与力を含む）とされる。秀吉の指示とする説がある。〔要確認〕
- 関ヶ原後も上杉家の家臣にとどまる（米沢30万石への減封後も執政）。〔要確認〕
- 参照資料：`reference/ndl/jozan-kidan.txt` に直江の逸話が多いが、OCRが粗く、秀吉との関係を示す条は未確認。

### 3. 主家の国を継いだ

#### 3-1. 鍋島直茂（龍造寺家）

- 龍造寺隆信の重臣で義弟（直茂の父・清房の後妻が隆信の母・慶誾尼）。〔要確認〕
- 天正12年（1584）、隆信が沖田畷で戦死。以後、政家を補佐して国政を担う。〔要確認〕
- 九州平定後の国分け：川角太閤記{{肥前は鍋島加賀守居城に被遣候}}。〔`reference/wikisource/kawasumi-taikoki.txt`。「居城に被遣」の中身（知行の宛行か、居城の安堵か）は要確認〕
- 天正18年（1590）、秀吉が政家を隠居させ、国政を直茂に委ねたとされる。〔要確認：秀吉朱印状の有無〕
- 文禄2年の同じ覚書に{{波多三河守事、鍋島加賀守与力被㆓仰付㆒上は}}、また九州出馬の折に波多の改易を{{鍋島束㆑手柔㆑面侘言申し付て}}免じたとある。〔`reference/wikisource/hoan-taikoki.txt`〕
- 慶長12年（1607）、高房・政家の死後、龍造寺家の領国を直茂の子・勝茂が継ぐ（佐賀藩）。〔要確認〕

### 4. 比べる

- 行き着いた先：①主家を離れて大名（宗茂・隆景）／②主家の中で主家並み（義弘・広家・兼続）／③主家の国を継ぐ（直茂）。
- 入口：どれも天下人の秀吉が、主家を通さずに直接取り立てた（名字・姓・官位・領国・与力）。与力を付けたことが文書で見えるのは義弘と直茂（文禄2年の覚書）、組下に置いたのは宗茂（川角太閤記）。
- 秀吉の理由（見立て）：功への報いに加え、服属させた大名家の中に直接つながる人を置き、内から押さえる。大友・毛利・島津・上杉・龍造寺は、どれも秀吉が服属させた大きな家。島津で当主の弟を重んじたのが最もはっきりした例。
- 天下人が替われば立場も揺らぐ：広家（徳川の世で毛利家の家臣扱い）。宗茂も関ヶ原で改易。

### 5. 当てはめ：織田家の時代の秀吉と秀長

- 構図は同じ：天下人＝信長、主家＝秀吉、家臣＝秀長。島津家の義弘と同じく、秀長は主家の当主の弟。
- 信長が秀長を直接取り立てた記録は、信長公記には見当たらない。〔`hidenaga-independence` の 2-2〕
- 理由の見立て：秀吉は信長自身の家臣で、羽柴家は織田家中の一部。外から押さえ込む必要のある家ではなく、弟を引き抜いて兄の家を割る理由が信長になかった。

## 反証の検討

- 反対説・自説の弱点：
  - 六人とも秀吉の時代の例。信長が他家の家臣（または自分の家臣の家臣）を直接取り立てた例を探していないので、「信長の下では道がなかった」は、秀長について記録がないことしか言えない。
  - 兼続・広家・義弘を「大名になった」と言えるかは怪しい。表題は六人をまとめた言い方にとどまる。
  - 「押さえるため」は動機の推測で、史料に書かれていない。
  - 六人の事実の多くは一般の知識による仮置き。
- それでもこう考える理由：
  - 少なくとも宗茂・隆景・直茂・義弘は、天下人から主家を通さずに領国・与力を与えられたことが、二次史料ながら秀吉時代の記事・文書に見える。天下人とじかにつながることが、家臣が主家の外に足場を持つ入口だった、とまでは言える。

## 結論

- 家臣が大名（並み）になる入口は、主家の上に立つ天下人による直接の取り立てだった。天下人が替われば、その立場も揺らいだ。
- 織田家の時代の秀長には、その取り立てがなかった。
